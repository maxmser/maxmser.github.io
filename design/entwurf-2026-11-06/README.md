# Design-Entwurf vom 06.11.2026

Dieser Ordner enthält einen statischen Entwurf für die Startseite. Er ist keine fertige Umsetzung, sondern die Vorlage für den Design-Durchgang in Hugo.

- `entwurf.css`: das CSS des Entwurfs. Grundeinheit ist eine Zeile Fließtext (18 Pixel Schrift, 27 Pixel Zeilenhöhe, im CSS `1rlh`). Das Raster hat 4 Spalten auf dem Handy, 8 ab 40em und 12 ab 64em.
- `startseite.html` und `startseite-mit-raster.html`: die Startseite mit den echten Platzhaltern, einmal ohne und einmal mit eingeblendetem Raster. Die Dateien lassen sich direkt im Browser öffnen.
- Die PNG-Dateien zeigen den Vergleich zwischen dem jetzigen Gerüst und dem Entwurf.

Im Entwurf ist Inter Display (optische Größe 32) für alle Texte eingestellt. Ob Display auch für den Fließtext gelten soll oder nur für Überschriften, ist noch nicht entschieden.

Hugo veröffentlicht diesen Ordner nicht, weil er außerhalb von content, static, assets und layouts liegt.
